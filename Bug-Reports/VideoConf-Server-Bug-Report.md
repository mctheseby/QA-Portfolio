# 🐞 Баг-репорт: Отсутствует валидация поля «Внешний адрес веб-страницы»

## 📋 Основная информация
- **Продукт:** Enterprise Video Conferencing Server
- **Версия:** v5.5.x, Windows 10, Chrome
- **Компонент:** Веб-панель — Настройки

## 🚨 Severity: Major
## 🎯 Priority: Medium

## 🔍 Шаги воспроизведения
1. Открыть Веб-панель → Настройки
2. В поле «Внешний адрес» ввести некорректное значение (например `https://abc`)
3. Нажать «Применить»

## ✅ Ожидаемый результат
Отображается сообщение об ошибке, адрес не сохраняется

## ❌ Фактический результат
Некорректный адрес принимается и сохраняется без каких-либо предупреждений

## 🔄 Воспроизводимость: Всегда

## 📊 Статус: Открыт

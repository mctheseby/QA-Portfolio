# ✅ Чек-лист тестирования веб-приложения

## 🔐 Аутентификация
- [ ] Вход с корректными данными
- [ ] Вход с неверным паролем — отображается ошибка
- [ ] Вход с пустыми полями — отображается валидация
- [ ] Поле пароля скрыто
- [ ] Сессия завершается по таймауту
- [ ] Выход очищает сессию

## 📝 Формы и валидация
- [ ] Обязательные поля валидируются
- [ ] Формат email проверяется
- [ ] Ограничения на максимальную длину соблюдаются
- [ ] Специальные символы обрабатываются корректно
- [ ] Отправка с пустыми обязательными полями — ошибка
- [ ] После успешной отправки отображается уведомление

## 🌐 UI и кроссбраузерность
- [ ] Chrome, Firefox, Safari — вёрстка корректна
- [ ] Адаптивность (375px, 768px, 1280px)
- [ ] Нет битых изображений и иконок
- [ ] Ссылки и кнопки кликабельны и ведут куда нужно
- [ ] Состояния загрузки отображаются

## 🔌 API (через Postman / DevTools)
- [ ] Корректные HTTP-статусы (200, 400, 404, 500)
- [ ] Ответы с ошибками содержат понятные сообщения
- [ ] Защищённые эндпоинты требуют авторизацию
- [ ] Пустые и null-значения обрабатываются корректно

## ⚡ Базовая производительность
- [ ] Страница загружается менее чем за 3 секунды
- [ ] Нет ошибок в консоли (DevTools)
- [ ] Нет битых запросов (4xx/5xx во вкладке Network)

## 🔒 Базовая безопасность
- [ ] Чувствительные данные не передаются в URL
- [ ] SQL-инъекция обрабатывается корректно
- [ ] XSS-атака обрабатывается корректно
